# Online Examination Portal — Angular Frontend

Angular frontend for an online examination portal.

## Overview
This repository contains the client-side application. Review the components, routes, services, and models to understand the implemented exam and user workflows.

## Related Project
- [Exam Portal Spring Boot Backend](https://github.com/MahiTzy/examportal-backend-springboot)

## Technology
- Angular 17.1.1
- TypeScript
- HTML and CSS
- Node.js and npm

## Prerequisites
- Node.js version compatible with Angular 17
- npm
- Backend service configured for local development, if API integration is required

## Getting Started
```bash
git clone https://github.com/MahiTzy/examportal-frontend-angular.git
cd examportal-frontend-angular
npm install
npx ng serve
```
Open [http://localhost:4200](http://localhost:4200).

## Configuration
Review environment files and Angular services for the backend API base URL. Use local environment configuration and do not commit credentials or private endpoints.

## Common Commands
- `npx ng build` — production build.
- `npx ng test` — run configured unit tests.
- `npx ng generate component component-name` — generate a component.
